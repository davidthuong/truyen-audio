Liên Kết Kênh YouTube (Google OAuth 2.0)

Khắc phục lỗi "redirect_uri_mismatch":
Trong Google Cloud Console, vào mục Credentials -> OAuth 2.0 Client IDs:
  • Nếu là Web application: Thêm vào mục Authorized redirect URIs đường dẫn bên dưới.
  • Hoặc khi tạo Client ID, chọn Application type = Desktop app (Khuyên dùng, không bị lỗi URI).
